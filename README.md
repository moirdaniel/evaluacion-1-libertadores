# API de la Copa Libertadores

Evaluación 1 · Módulo 3: Backend y APIs REST.

API creada con Node.js y Express para consultar clubes de la Copa Libertadores, filtrarlos por país y obtener los años de sus títulos.

## Cómo ejecutar

Requisitos: Node.js 20 o superior y Yarn.

Desde la carpeta del proyecto:

```bash
yarn
yarn dev
```

El servidor funciona en el puerto **3000**: http://localhost:3000.
